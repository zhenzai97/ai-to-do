## 2. 环境准备

### 步骤 1：初始化 Vue 3 项目

**操作**：

1. 创建 `package.json`，依赖 `vue`，开发依赖 `vite`、`@vitejs/plugin-vue`。
2. 创建 `vite.config.js`，注册 Vue 插件。
3. 修改 `index.html`，挂载点 `#app`，引入 `/src/main.js`。

**验收**：`npm install` 无报错。

---

### 步骤 2：创建应用入口

**操作**：

1. `src/main.js`：`createApp(App).mount('#app')`。
2. `src/App.vue`：引入并渲染 `TodoApp`。
3. 引入 `src/assets/main.css`。

**验收**：`npm run dev` 后页面可访问（即使尚无内容）。

---

## 3. 功能实现

### 步骤 3：实现 storage 工具

**文件**：`src/utils/storage.js`

- `loadTasks()` / `saveTasks()` / `generateId()`
- 键名 `ai-todo-tasks`，与旧版数据格式兼容

---

### 步骤 4：实现 useTasks Composable

**文件**：`src/composables/useTasks.js`

1. `tasks = ref(loadTasks())`
2. `computed`：`sortedTasks`、`activeCount`、`completedCount`
3. `watch(tasks, saveTasks, { deep: true })`
4. 实现 `addTask`、`toggleTask`、`deleteTask`

**验收**：在组件中调用后，控制台可见 localStorage 更新。

---

### 步骤 5：实现 TaskItem 组件

**文件**：`src/components/TaskItem.vue`

- Props：`task`、`removing`
- Emits：`toggle`、`delete`
- 复选框 + 文本 + 删除按钮
- `completed` 类名控制删除线

---

### 步骤 6：实现 TodoApp 主组件

**文件**：`src/components/TodoApp.vue`

1. 使用 `useTasks()` 获取状态与方法
2. 表单 `@submit.prevent` + `v-model` 输入
3. 统计区绑定 `activeCount` / `completedCount`
4. `TransitionGroup` 渲染任务列表
5. 空列表显示提示文案

**验收**：添加、勾选、删除、统计、持久化全流程可用。

---

### 步骤 7：迁移样式

**文件**：`src/assets/main.css`

- 保留蓝色主题、圆角、阴影、响应式断点
- 新增 `.task-enter-active` 入场动画
- `.task-item.removing` 删除淡出

## 6. 与旧版（原生 JS）的差异

| 方面 | 旧版 | Vue 3 版 |
|------|------|----------|
| 渲染 | 手动 `createElement` | 声明式模板 + `v-for` |
| 状态 | 普通对象 + 手动 render | `ref` / `computed` 响应式 |
| 持久化 | 每次操作手动 save | `watch` 自动同步 |
| 列表动画 | 手动 classList | `TransitionGroup` |
| 构建 | 无需构建 | Vite 开发与打包 |

数据格式与 `localStorage` 键名保持不变，升级后原有任务数据可继续使用。
