# 待办事项应用 — 需求文档

## 1. 项目概述

| 项目 | 说明 |
|------|------|
| 项目名称 | AI To-Do（待办事项应用） |
| 项目类型 | 纯前端单页 Web 应用 |
| 技术栈 | Vue 3 + Vite + Element Plus + GSAP + SCSS |
| 数据持久化 | 浏览器 `localStorage` |
| 目标用户 | 需要轻量记录日常任务的个人用户 |

本应用提供简洁的任务管理能力：添加、完成标记、删除任务，并统计完成情况。无需后端与账号，数据保存在本地浏览器中。

---

## 2. 功能需求

### 2.1 添加任务

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| F-001 | 用户可在输入框中填写任务内容 | 必须 |
| F-002 | 点击「添加」按钮或按 Enter 键将任务加入列表 | 必须 |
| F-003 | 空内容或仅空白字符时不允许添加，并给予提示 | 必须 |
| F-004 | 新任务默认状态为「未完成」 | 必须 |

### 2.2 标记完成

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| F-005 | 每条任务前显示复选框 | 必须 |
| F-006 | 点击复选框可切换完成 / 未完成状态 | 必须 |
| F-007 | 已完成任务的文本显示删除线样式 | 必须 |

### 2.3 删除任务

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| F-008 | 每条任务右侧显示删除按钮 | 必须 |
| F-009 | 点击删除按钮后，该任务从列表中移除 | 必须 |

### 2.4 任务统计

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| F-010 | 界面显示当前未完成任务数量 | 必须 |
| F-011 | 界面显示当前已完成任务数量 | 必须 |
| F-012 | 统计数字随任务增删及状态变化实时更新 | 必须 |

### 2.5 数据持久化

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| F-013 | 所有任务数据保存至 `localStorage` | 必须 |
| F-014 | 刷新页面或关闭后重新打开，任务列表与状态保持不变 | 必须 |
| F-015 | 每次增删改操作后立即同步到本地存储 | 必须 |

## 3. 界面需求

### 3.1 整体风格

- 简洁、现代、易读
- 主色调为清新蓝色系，辅以白色与浅灰背景
- 圆角输入框、按钮与卡片容器
- 适度阴影，增强层次与焦点感
- 布局居中，留白合理

### 3.2 组件说明

| 区域 | 说明 |
|------|------|
| 页头 | 应用标题与简短副标题 |
| 输入区 | 任务输入框 + 添加按钮，横向排列 |
| 统计区 | 未完成 / 已完成数量展示 |
| 列表区 | 任务项：复选框 + 文本 + 删除按钮 |
| 空状态 | 无任务时显示友好提示文案 |

### 3.3 响应式要求

| 断点 | 行为 |
|------|------|
| 桌面（≥ 768px） | 输入框与按钮同一行，列表宽度适中居中 |
| 移动（< 768px） | 输入区可纵向堆叠，触控区域足够大，文字不溢出 |

### 3.4 交互反馈

- 按钮 hover / active 状态可见
- 删除操作可有短暂过渡动画
- 复选框切换时任务样式即时变化

## 4. 非功能需求

| 编号 | 类别 | 描述 |
|------|------|------|
| 兼容性 | 支持现代浏览器（Chrome、Firefox、Edge、Safari 近期版本） |
| NF-002 | 性能 | 任务量在数百条以内时操作流畅 |
| NF-003 | 可维护性 | 组件化结构，逻辑与视图分离（Vue 3 Composition API） |
| NF-004 | 无障碍 | 表单控件具备可访问标签，按钮可键盘操作 |

---

## 5. 数据模型

每条任务（Task）包含以下字段：

```json
{
  "id": "string（唯一标识，如 UUID 或时间戳）",
  "text": "string（任务内容）",
  "completed": "boolean（是否已完成）",
  "createdAt": "number（可选，创建时间戳）"
}
```

本地存储键名建议：`ai-todo-tasks`  
存储格式：JSON 数组 `[Task, ...]`

---

## 6. 验收标准

1. 能正常添加、完成、删除任务，统计数字正确。
2. 已完成任务显示删除线，未完成无删除线。
3. 刷新页面后数据不丢失。
4. 手机宽度下布局可用，无横向滚动条（除必要滚动区域外）。
5. 界面符合蓝色清新风格，圆角与阴影效果可见。
