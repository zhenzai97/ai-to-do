# 待办事项应用 — 功能模块文档

## 1. 模块总览

```
┌──────────────────────────────────────────────────────────────────┐
│                      待办事项应用 (Vue 3)                          │
├──────────┬──────────┬──────────┬──────────┬──────────┬──────────┤
│ 视图组件层 │ Composable│ Pinia Store│ 存储工具层 │ 主题/筛选  │ 样式/GSAP │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘
```

| 模块 | 文件 | 职责 |
|------|------|------|
| 入口 | `src/main.js` | 创建 Vue 应用、Pinia、Element Plus |
| 根组件 | `src/App.vue` | 提供主题上下文（`provide/inject`） |
| 视图组件层 | `src/components/` | 页面 UI 与交互绑定 |
| Pinia Store | `src/stores/tasks.js` | 任务状态集中管理 |
| Composable | `src/composables/useTasks.js` | Store 封装，供组件调用 |
| Composable | `src/composables/useFilter.js` | 任务筛选（全部 / 进行中 / 已完成） |
| Composable | `src/composables/useTheme.js` | 浅色 / 深色主题切换 |
| 存储工具层 | `src/utils/storage.js` | localStorage 读写与数据规范化 |
| 样式 | `src/styles/` + 组件 SCSS | CSS 变量主题、BEM 嵌套 |
| UI 框架 | Element Plus | 输入框、按钮、标签、对话框等 |
| 动画 | GSAP + `useGsapContext.js` | 入场、增删、统计弹跳、输入抖动 |

## 2. 视图组件层

### 2.1 组件树

```
App.vue
└── TodoApp.vue
    ├── ThemeToggle.vue        # 主题切换
    ├── 输入表单（内联）
    ├── TaskFilter.vue         # 筛选 Tab
    ├── 统计区（内联）
    └── TaskItem.vue × N
```

### 2.2 TodoApp.vue

| 职责 | 说明 |
|------|------|
| 表单提交 | 添加任务（含优先级） |
| 筛选展示 | `TaskFilter` + `filteredTasks` |
| 批量操作 | 全部清空、清除已完成（均带确认） |
| 列表渲染 | 最多显示 6 条，超出内部滚动 |
| 布局 | 整页无滚动条，仅列表区域滚动 |

### 2.3 TaskFilter.vue

| Props | 说明 |
|-------|------|
| `modelValue` | 当前筛选：`all` / `active` / `completed` |

| Emits | 说明 |
|-------|------|
| `update:modelValue` | 切换筛选条件 |

### 2.4 TaskItem.vue

| Props | 类型 | 说明 |
|-------|------|------|
| `task` | Object | `{ id, text, completed, priority, createdAt }` |

| Emits | 说明 |
|-------|------|
| `toggle` | 切换完成状态 |
| `delete` | 删除任务（GSAP 动画后触发） |
| `update` | 编辑任务内容与优先级 |

### 2.5 ThemeToggle.vue

通过 `inject('theme')` 调用 `toggleTheme()`，切换 `data-theme` 属性。

## 3. Pinia Store（tasks.js）

### 3.1 State

```javascript
tasks  // Task[]，从 localStorage 初始化
```

### 3.2 Getters

| Getter | 说明 |
|--------|------|
| `sortedTasks` | 按优先级权重 + 创建时间排序 |
| `activeCount` | 未完成任务数 |
| `completedCount` | 已完成任务数 |

### 3.3 Actions

| Action | 说明 |
|--------|------|
| `addTask(text, priority)` | 添加任务 |
| `updateTask(id, payload)` | 编辑任务 |
| `toggleTask(id)` | 切换完成状态 |
| `deleteTask(id)` | 删除单条 |
| `clearAllTasks()` | 清空全部 |
| `clearCompleted()` | 清除已完成 |

### 3.4 持久化

`setupTaskStorePersistence(store)` 通过 `$subscribe` 深度监听，自动写入 `localStorage`。

## 4. Composable 模块

### 4.1 useFilter

| 导出 | 说明 |
|------|------|
| `filter` | 当前筛选 ref |
| `filteredTasks` | 筛选后的任务列表 computed |
| `FILTER_OPTIONS` | 筛选项配置 |

### 4.2 useTheme

| 导出 | 说明 |
|------|------|
| `theme` | `light` / `dark` |
| `isDark` | 是否深色模式 |
| `toggleTheme()` | 切换并持久化到 localStorage |

---

## 5. 数据流

```
用户操作 → TodoApp / TaskItem
    → Pinia Store actions 修改 tasks
    → $subscribe 触发 saveTasks
    → getters / useFilter 更新视图
```

## 7. 扩展点（已实现）

| 扩展 | 实现方式 | 文件 |
|------|----------|------|
| 筛选 Tab | `useFilter` + `TaskFilter.vue` | `composables/useFilter.js`、`components/TaskFilter.vue` |
| 清除已完成 | `clearCompleted()` + 确认对话框 | `stores/tasks.js`、`TodoApp.vue` |
| Pinia 状态管理 | `useTaskStore` 统一管理任务 | `stores/tasks.js` |
| 暗色主题 | CSS 变量 + `data-theme` + `provide/inject` | `composables/useTheme.js`、`styles/global.scss` |

## 8. 布局约束

| 约束 | 实现 |
|------|------|
| 页面无滚动条 | `html/body/#app` 设置 `height: 100%; overflow: hidden` |
| 卡片自适应视口 | `.todo-app__card` 使用 `max-height: 100%` + flex 布局 |
| 列表最多显示 6 条 | `.todo-app__list` 设置 `max-height` + `overflow-y: auto` |
